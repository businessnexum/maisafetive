# Mais Afetivê

Site da Mais Afetivê Cafeteria, desenvolvido como uma página estática.

## Desenvolvimento

```bash
npm run dev
```

## Build

```bash
npm run build
```

O build estático é gerado em `dist/`. A experiência completa foi preparada para telas mobile; em telas maiores, o site apresenta um aviso para acessar pelo celular.

As sequências de scroll usam imagens em `public/frames/afetive-film` e `public/frames/afetive-mobile`.
